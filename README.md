# Personal Profile System

A beginner C program that collects and displays personal information while practicing core C programming concepts.

## Overview

The Personal Profile System was built as part of my journey learning C programming through hands-on projects.

The program collects basic user information and displays a formatted profile based on the provided data.

## Features

- Accepts user input
- Stores personal information using variables
- Compares strings using `strcmp()`
- Displays formatted information
- Uses conditional statements
- Works with different C data types

## Concepts Practiced

- Variables
- Data types
- `char` arrays and strings
- `printf()`
- `scanf()`
- String comparison with `strcmp()`
- Conditional statements
- Header files
- Basic C program structure
